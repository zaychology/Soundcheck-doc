---
title: "VoiceMaster"
description: "Create temporary voice channels members can manage themselves."
---

VoiceMaster creates a personal, temporary voice channel when a member joins the configured creation channel. The channel owner can manage access and settings without needing a moderator.

## Set up VoiceMaster

1. Run `/voicemaster setup` as a server manager.
2. Review the configuration with `/voicemaster configuration`.
3. Optionally post the control panel using `/voicemaster sendinterface`.
4. Set defaults for name, role, region, interface, or bitrate under `/voicemaster default`.

## Member controls

While in a VoiceMaster channel, members can use `/voicemaster lock`, `unlock`, `ghost`, `unghost`, `permit`, `reject`, `name`, `limit`, `bitrate`, `transfer`, `claim`, `status`, and `music`.

`lock` and `unlock` control who can join. `ghost` and `unghost` control channel visibility. `permit` and `reject` manage individual access. `transfer` hands ownership to another member; `claim` lets an eligible member take an orphaned channel.

## Admin controls

Use `/voicemaster role` to configure eligible roles, `/voicemaster join role` to control join behavior, and `/voicemaster category private` for private-channel behavior. `/voicemaster reset` removes the configuration when you no longer want to use VoiceMaster.
