---
title: "Artist tracking"
description: "Search trackers, eras, snippets and compilations."
---

Trackers are Google Sheets that fan communities keep up to date with an artist's songs, eras, videos, art and samples. Soundcheck reads them live, so results match the sheet.

Every tracker command starts with an optional `tracker` option. Pick an artist there, or leave it blank to use your server's or your own default (see [Use Soundcheck](/getting-started/using-soundcheck#pick-an-artist)).

## Search songs

| Command | Finds |
| --- | --- |
| `/tracker search` | Released and unreleased songs together, or one tab with `sheet` |
| `/tracker unreleased` | Unreleased songs |
| `/tracker released` | Released songs |
| `/tracker recent` | The 25 newest unreleased entries |
| `/tracker random` | A random song |

`title`, `artist` and `producer` can be combined. Separate several names with `;` and they can be in any order, for example `artist:Ken Carson;Destroy Lonely`. Results are ranked best match first, 100 per page.

## Everything else in a tracker

| Command | Finds |
| --- | --- |
| `/tracker era` | An era's dates, songs and artwork |
| `/tracker musicvideos` | Music videos |
| `/tracker albumcopies` | Album copies |
| `/tracker tracklists` | Tracklists |
| `/tracker art` | Cover art |
| `/tracker samples` | Samples |
| `/tracker instagramlives` | Instagram Lives |
| `/tracker link` | The link to the tracker sheet |

Not every tracker has every tab. If a tab is missing, the command says so.

## Any tracker, not only ours

- **TrackerHub.** Every tracker listed on TrackerHub shows up in the `tracker` option too. `/trackerhub` searches TrackerHub's list.
- **Your own sheet.** `/tracker load <link>` adds any public Google Sheets tracker to your own `tracker` list for 7 days. You can keep up to 5.

## Snippets and compilations

- `/snippets` searches an artist's archived snippets by name. Until Discord grants Soundcheck access to message content, results can't play the clips; use **Open Post** (and **Join snippets server** if you aren't in it) to watch them.
- `/compilation` searches an artist's compilation, or gives its link.
- `/refreshsnippets` reloads the snippet list. It needs Manage Messages.

## Server artist and eras

- `/artist set` picks the server's default artist, `/artist config` shows it and `/artist reset` clears it. `/artist mine` sets your own. These need [Premium](/administration/premium).
- `/era add`, `edit`, `delete` and `reorder` let server managers keep their own era list for the server's artist.
- `/surface` posts a track from the server's artist into the channel. It needs Premium and Manage Messages.
