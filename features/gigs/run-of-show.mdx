The **Run of Show** is the minute-by-minute plan for a gig: every song, announcement, break, and cue in the order they happen, grouped into named parts of the night. It lives at the top of the gig's **Details** tab so it's the first thing you and the crew see when they open the show. It's built to stay live right up to — and during — the event, with everything saving automatically as you work.

<Info>
  Run of Show is a feature-gated capability. Where it isn't enabled, a gig still has the lighter [day-of timeline](#the-day-of-timeline). If you expect Run of Show but don't see it on your gig, contact [info@soundchecklive.io](mailto:info@soundchecklive.io).
</Info>

## How the Run of Show is organized

A run of show is a list of **sections**, and each section holds an ordered list of **items**.

- A **section** is a named stretch of the night — *Cocktail Hour*, *Dinner*, *Main Set*, *Encore*. Give each section a name so the crew can follow along, and add an optional note for that stretch of the show.
- An **item** is a single cue within a section. Every item has a type:

| Item type | Use it for |
|---|---|
| **Song** | A number from the setlist or song library. |
| **Announcement** | A spoken moment: a toast, an MC intro, a dedication. |
| **Break** | A pause: set break, dinner service, stage changeover. |
| **Note** | Anything else the crew needs to know at that moment. |

Each item can carry timing, free-text notes, and its own attachments — a chart, a lyric sheet, or a cue card sits right on the item where the crew needs it.

## Build the Run of Show

<Steps>
  <Step title="Enter edit mode">
    On the gig's **Details** tab, find the **Run of Show** panel and choose **Edit**.
  </Step>
  <Step title="Add sections">
    Choose **Add section** and give each part of the night a name. Drag sections up or down to set the order.
  </Step>
  <Step title="Add items inside each section">
    Inside a section, choose **Add item** and pick the item type. For a **Song** item, use the song picker to choose from the gig's linked setlists or your organization's song library. For all other item types, give it a title and any notes the crew needs.
  </Step>
  <Step title="Set timing and attach files">
    Add a start time or duration to each item. Attach charts, lyric sheets, cue cards, or other files directly to the item — they show up in context, not buried in a general file pile.
  </Step>
  <Step title="Reorder via drag-and-drop">
    Drag any item within its section to change its position in the run. Drag sections themselves to reorder the parts of the night.
  </Step>
  <Step title="Exit edit mode">
    Choose **Done** to leave edit mode. Your changes were already saved as you worked — you don't need to press a Save button.
  </Step>
</Steps>

<Tip>
  Toggle **Show durations** to display each item's length and watch the run's total timing build up as you add cues. This makes it easy to spot if a set is running long before the show.
</Tip>

## Autosave and editing safely

You never press Save. As you edit, Run of Show **autosaves in the background** and shows its state — *Saving…*, *Locked in*, or *Save missed* with a **Retry** option — so you always know whether your work is captured. If a save can't complete, Soundcheck warns you before you navigate away rather than letting the edit disappear silently.

### When two people edit at once

Run of Show is often touched by more than one person around show time — a coordinator locking in the order while a music director adds a late song change. If the run of show changes somewhere else while you're editing, Soundcheck detects the conflict and offers to **merge your edits** on top of the newer version rather than silently overwriting either set of changes. You'll see a heads-up:

> *"Updated elsewhere. Your edits merged in; give the show flow a quick scan."*

Review the merged order to confirm everything looks right. If you'd rather not merge, you can pause the save and reload when ready.

## Run of Show templates

Most organizations run the same shapes of night repeatedly: a wedding reception, a corporate dinner, a festival slot. **Templates** let you save that shape once and apply it to any new gig, so every show starts from a real rundown instead of a blank page.

Templates live under **Run of Show** in the sidebar and belong to your whole organization — everyone who manages gigs sees the same library.

### Creating a template

Two paths in:

- **New Template**: choose **New template** on the templates page to build a template from scratch in the same editor as a gig's run of show.
- **Save from a gig**: on any gig whose run of show you want to reuse, open the Run of Show section's **⋯** menu and choose **Save as Template**. It copies every section, item, song, and attachment exactly as they stand.

### Applying a template to a gig

<Steps>
  <Step title="Open the Run of Show on the gig">
    Navigate to the gig's **Details** tab and find the Run of Show section.
  </Step>
  <Step title="Choose Apply Template">
    Tap **Apply Template** (or **Use Template** if the run of show is still empty) and pick from your organization's template library.
  </Step>
  <Step title="Confirm the replace">
    Applying a template **replaces** the gig's entire current run of show. If the gig already has content, Soundcheck asks you to confirm before overwriting. Templates with no sections or items can't be applied over an existing run of show, so an empty template can never accidentally wipe your show flow.
  </Step>
</Steps>

Times re-anchor to the gig automatically: if the gig has a start time, every item shifts so the run begins at that time, keeping original spacing intact. A template built around a 6 PM show applied to a 7 PM gig moves everything an hour later.

## Export to PDF

When you need a printed run of show — for the stage, the sound board, or the client — choose **Export** to open the export builder. You control which fields appear (time, item-type label, instructions, notes, attachments), set font and layout preferences, and optionally include your organization's logo. A live preview updates as you adjust settings. Choose **Export PDF** to download the document.

<Note>
  PDF export uses your saved preferences from the last export, so recurring shows don't require setup every time.
</Note>

## How crew see the Run of Show on mobile

The Soundcheck mobile app surfaces the Run of Show on the gig's Details screen. Crew members assigned to the gig can read the full show flow, including section names, item types, timing, and any attached charts or cue cards. The app caches the run of show for offline use, so crew can pull it up at a venue with no signal. Last-minute edits you save on web sync to mobile the next time the app connects.

## Relationship to setlists

The Run of Show and your [setlists](/features/setlists/overview) share one song library. When you add a **Song** item, the picker offers songs from the gig's linked setlists and your org's full song library — so the two stay in sync rather than drifting apart. You can also add a new song to the library right from the picker while you build the run of show.

Think of it this way: the **setlist** is *what you're playing*. The **run of show** is *everything that happens, and when*, with the songs slotted into their place in the night.

## The day-of timeline

Alongside (or instead of) Run of Show, every gig's Details tab includes a lighter **Timeline** section: a simple list of day-of segments with a name, start time, end time, and notes.

```
2:00 PM  Load-in begins
3:00 PM  Sound check
6:00 PM  Doors open
7:00 PM  First set (45 min)
9:00 PM  Load-out
```

Add items, drag to reorder, and edit inline. Use the Timeline when you just need load-in through load-out and don't need the full section-by-section run of show.
