---
title: "Levels and rewards"
description: "Message XP, leaderboards and role rewards."
---

Members earn XP by chatting. Server managers can hand out roles at set levels.

## For members

- `/levels` shows your level, or another member's.
- `/levels leaderboard` shows the top members.
- `/levels roles` lists the reward roles.

## Set it up

Turn leveling on with `/levels unlock` and off with `/levels lock`. These need Manage Server.

| Command | What it does |
| --- | --- |
| `/levels add <role> <rank>` | Give a role at a level |
| `/levels update <role> <rank>` | Change the level for a reward role |
| `/levels remove <rank>` | Remove a reward |
| `/levels stackroles` | Keep earlier reward roles, or keep only the highest |
| `/levels messagemode` | Choose where level-up messages go |
| `/levels setrate` | Change how fast XP builds up |
| `/levels ignore` | Stop a channel or role from earning XP |
| `/levels list` | Show ignored channels and roles |
| `/levels config` | Show all level settings |
| `/levels leaderboard rename` | Change the leaderboard's title |

## Fix XP

`/levels setxp`, `/levels removexp` and `/levels setlevel` change one member. `/levels cleanup` resets members who left. `/levels reset` resets everyone and needs Administrator, so use it carefully.

<Note>
`/levels sync`, which re-checks every member's reward roles, needs Soundcheck to see the member list. Discord hasn't given Soundcheck that permission yet, so it may not find everyone.
</Note>
