The Song Library is the foundation of every setlist you build in Soundcheck. Instead of re-entering song details show after show, you maintain one shared catalog for your organization — titles, artists, durations, keys, tempos, and any attached charts or media links — and drop songs from it into any setlist with a single click. The library grows once; every setlist benefits forever.

## Accessing the Song Library

Navigate to **Music Management** in the main navigation, then select the **Song Library** tab. From there you can browse your full catalog, search by title or artist, sort and filter, and add or edit songs.

## Adding songs manually

### Quick add

When you need a song in a setlist right away and don't have time for a full entry:

1. Click **+ Add Song**.
2. Enter the song title (required).
3. Optionally add the artist name.
4. Click **Save**.

The song is now in your library and available for setlists. Fill in the remaining fields later.

### Full entry

For a complete, permanent record that works best in setlist timing calculations:

1. Click **+ Add Song**.
2. Fill in the fields described below.
3. Add any media links.
4. Click **Save**.

## Song fields

| Field | Required | Description | Example |
|---|---|---|---|
| **Title** | Yes | The song name as you'll recognize it in setlists | *Take Five* |
| **Artist** | No | Original or performing artist — helpful for covers and tribute acts | *Dave Brubeck Quartet* |
| **Duration** | No | Length in MM:SS — used for automatic running-time calculations | `5:24` |
| **Key** | No | Musical key of your arrangement (major, minor, sharp, flat) | `Eb minor` |
| **Tempo** | No | Beats per minute — useful for flow planning and click tracks | `176 BPM` |
| **Notes** | No | Free-text performance notes: arrangement cues, energy level, special instructions | *"Extended solo section"* |
| **Charts / Lyrics / Media Links** | No | External URLs to chord charts, lead sheets, lyrics, audio, or video references | Google Drive, YouTube, SoundCloud |

<Note>
Accurate durations are what make running-time calculations reliable. If you're building setlists against a contracted time slot, complete the Duration field for every song in your catalog.
</Note>

## Attaching charts, lyrics, and media links

Each song can carry multiple media links — one for the chord chart, one for the lyrics sheet, one for a reference recording, and so on. To add a link:

1. Open the song for editing.
2. Scroll to **Media Links** and click **Add Link**.
3. Choose a type (Chord Chart, Lyrics, Sheet Music, Audio, Video, or Other).
4. Paste the URL and add an optional title or description.
5. Save the song.

The links appear when any team member opens the song on web or mobile, so everyone has the right resources before doors. Host files on Google Drive, Dropbox, or wherever your team already shares documents — just make sure sharing permissions allow all members to open the link.

## Importing an album from Spotify

<Tip>
Use Spotify import when you need to populate your library with a full album's worth of songs at once. Track titles, artist names, and durations come in automatically — you only need to add arrangement-specific details (key, notes, media links) afterwards.
</Tip>

To import from Spotify:

1. Go to the **Song Library** tab.
2. Click **Import from Spotify**.
3. Search for an album or artist.
4. Select the tracks you want to import.
5. Click **Import** — basic information pre-fills from Spotify.
6. Open each imported song to add key, tempo, performance notes, and media links.

## Searching and filtering

Use the search box at the top of the Song Library to find songs by title or artist as you type. Sort results by:

- Title (A–Z or Z–A)
- Artist
- Duration
- Key
- Tempo
- Recently added

Filter the list to narrow results by key (for example, only songs in C major), tempo range (songs between 120–140 BPM), or whether a song has media links attached.

## Editing and deleting songs

**To edit a song**, click it in the library to open the detail view, click **Edit**, make your changes, and save. Updates apply everywhere that song appears — every setlist that contains it reflects the new data immediately.

**To delete a song**, click the delete icon and confirm. Deleting a song removes it from every setlist it appears in and recalculates those setlists' running times. This action cannot be undone, so check setlist usage before deleting anything in active rotation.

## Who can manage the library

The Song Library is shared across your organization. The following roles can add, edit, and delete songs:

- **Owners**
- **Admins**
- **Gig Coordinators**

Members assigned to a gig can view the songs in that gig's attached setlist, but they cannot add to or modify the library. If your team builds out the library together, divide the work among coordinators and admins to get it done faster.
