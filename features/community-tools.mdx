## Information

Use `/botinfo`, `/serverinfo`, `/userinfo`, `/channelinfo`, and `/roleinfo` to inspect Discord objects. `/membercount`, `/guildicon`, `/guildbanner`, `/splash`, `/avatar`, `/banner`, `/serveravatar`, `/serverbanner`, `/uptime`, and `/ping` provide focused server and profile information.

## Community tools

`/quickpoll` creates a quick poll. `/afk` sets an AFK status and `/afk mentions` controls mention behavior. `/weather` returns weather for a location, while `/topcommands` shows command-use statistics.

## Embeds and emojis

Members with the required permissions can use `/embed create`, `edit`, `copy`, `json`, and `fromjson` to manage rich messages. The `/emoji` group adds, renames, deletes, and lists server emojis; `/emoji app` manages application emojis.

## Fun commands

Soundcheck also includes `/grail`, `/translate`, `/uselessfact`, `/randomnumber`, `/coinflip`, `/rockpaperscissors`, `/8ball`, `/tic-tac-toe`, and `/connect4`.
