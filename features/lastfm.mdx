---
title: "Last.fm"
description: "Connect a Last.fm account and view listening data in Discord."
---

Link your Last.fm account with `/lastfm login <username>`. Soundcheck saves the username for your Discord account. Use `/lastfm logout` to remove it.

## Listening commands

| Command | Purpose |
| --- | --- |
| `/lastfm now` | Show what you are currently scrobbling |
| `/lastfm recent` | View recent tracks |
| `/lastfm topartists` | View top artists for a period |
| `/lastfm toptracks` | View top tracks for a period |
| `/lastfm topalbums` | View top albums for a period |
| `/lastfm whois` | View a Last.fm profile |
| `/lastfm count` | View total scrobble count |
| `/lastfm color` | Set the color of your Last.fm cards |

`/nowplaying` is a shortcut for the now-playing command.

Most commands take an optional `member`, so you can see another member's listening once they've linked their account. The top charts also take a `period`.
