---
title: "Last.fm"
description: "Connect a Last.fm account and view listening data in Discord."
---

Link your Last.fm account with `/lastfm login`. Soundcheck guides you through the authorization flow, then stores the connection for your Discord account. Use `/lastfm logout` to remove it.

## Listening commands

| Command | Purpose |
| --- | --- |
| `/lastfm now` | Show what you are currently scrobbling |
| `/lastfm recent` | View recent tracks |
| `/lastfm topartists` | View top artists for a period |
| `/lastfm toptracks` | View top tracks for a period |
| `/lastfm topalbums` | View top albums for a period |
| `/lastfm whois` | View a Last.fm profile |
| `/lastfm count` | View total scrobble count |
| `/lastfm color` | Set your preferred Last.fm embed color |

`/nowplaying` is a shortcut for the now-playing command.

<Note>
For another person’s public profile, use the relevant command with their Last.fm username when the command offers that option. Your own account must be linked for personalized defaults.
</Note>
