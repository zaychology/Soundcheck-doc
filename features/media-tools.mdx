Soundcheck includes tools for the music links and files your community shares every day.

## Supported platforms

Use `/spotify`, `/soundcloud`, `/youtube`, `/tiktok`, or `/x` with a supported link. The `info` subcommands on Spotify, SoundCloud, and YouTube return details for a resource. X and TikTok commands retrieve supported media content from their links.

## File utilities

| Command | Purpose |
| --- | --- |
| `/exiftool` | Read metadata from a supplied file |
| `/tag` | Add or edit supported audio metadata |
| `/spectrogram` | Generate a spectrogram from audio |
| `/cover` | Retrieve or work with cover art |
| `/runtime` | Estimate MP3 duration from its size and bitrate |
| `/identify` | Identify a song from audio using fingerprinting |
| `/download` | Download supported media from an accepted source |

## Music lookup

Use `/surface` to surface relevant music material and `/trackerhub` to locate an artist tracker. The Genius commands provide lyrics-adjacent artist, album, credits, related-song, and statistics lookup.

<Warning>
Only upload or download content you have the right to use. Source availability and platform restrictions can affect individual requests.
</Warning>
