## Download from a link

`/download <link>` sends the file back to the channel. It works with SoundCloud, TikTok, X and Pillowcase links. `/x style` picks how X posts look: an embed or a card.

Shortcuts: send `@Soundcheck <link>`, or right-click any message with a link and pick **Apps → Download media**.

<Note>
YouTube downloads aren't available. YouTube blocks the servers Soundcheck runs on.
</Note>

## Look up a link

| Command | Shows |
| --- | --- |
| `/spotify`, `/spotify info` | Spotify search, or details for a Spotify link |
| `/soundcloud`, `/soundcloud info` | SoundCloud search, or details for a SoundCloud link |
| `/youtube`, `/youtube info` | YouTube search, or details for a video |
| `/tiktok`, `/x` | A TikTok or X profile |

## Check an audio file

Attach a file or paste a link.

| Command | What it does |
| --- | --- |
| `/media spectrogram` | Draws a spectrogram, so you can see a file's real quality |
| `/media tag` | Opens a tag editor for an MP3 or M4A file |
| `/media exiftool` | Shows a file's metadata |
| `/media cover` | Adds a Parental Advisory label to an image |
| `/identify` | Names the song from its audio |
| `/runtime` | Estimates an MP3's length from its size and bitrate (slash only) |

## Genius

`/genius` searches Genius. `/genius credits` shows producers, writers and features, `/genius related` shows samples, interpolations and remixes, `/genius album` shows a tracklist, `/genius artist` and `/genius artist songs` show an artist, and `/genius stats` shows pageviews.

<Warning>
Only download or share content you have the right to use.
</Warning>
