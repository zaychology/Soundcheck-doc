The Soundcheck mobile app is your on-the-road companion to the web app. It's built for the moments between the desk — getting to load-in, confirming a crew response, glancing at tonight's setlist, or opening an invitation from Mailbox while you're backstage. The same account, the same data, accessible anywhere.

<Note>
  The mobile and web apps share the same data and the same login. Sign in once on each device and your gigs, crew, and Mailbox show up everywhere.
</Note>

---

## Who the mobile app is for

**Performing members and crew** use the app to read tonight's details, accept invitations, and answer availability checks without needing a laptop. **Bandleaders and coordinators on the road** use it to confirm tomorrow's lineup and push a last-minute change from the venue floor the moment plans shift.

If you spend most of your time building gigs, importing leads, or running finances, the **web app** at [app.soundchecklive.io](https://app.soundchecklive.io) is the better daily driver. Some editor-heavy work — advanced gig setup, CRM pipeline management, billing — lives there.

---

## What you can do on mobile

- **Accept or decline invitations** directly from your Mailbox
- **View gig details** — venue, call times, schedule, and team
- **Read tonight's setlist** including charts and notes you've already opened
- **Respond to availability requests** from your coordinator
- **Receive push notifications** for time-sensitive items: new invitations, crew responses, gig changes
- **Push last-minute changes from the floor** — update call times, notify crew about changes, and keep the run of show current when plans shift at the venue

## The four-tab layout

The app uses a bottom navigation bar with up to four tabs:

| Tab | What's there |
| --- | --- |
| **Gigs** | Your events. Open any gig to see its core details. Always available. |
| **Mailbox** | Invitations, crew offers, and availability checks. The heart of the mobile experience. |
| **Browse** | Your organization's modules: setlists, songs, CRM, teams, tasks, files, and more. |
| **You** | Your profile, availability settings, and personal and organization settings. |

<Info>
  The **Gigs** tab is always present. Some organizations configure Mailbox or Browse differently. If a tab you expect is missing, check with your organization Admin or use the web app.
</Info>

## Mobile vs. web: what lives where

Some features are best on web; others are built for the phone. Here's the breakdown:

| Task | Mobile | Web |
| --- | :---: | :---: |
| Accept / decline invitations | ✓ | ✓ |
| View gig details and setlists | ✓ | ✓ |
| Respond to availability requests | ✓ | ✓ |
| Push notifications | ✓ | — |
| Offline access to cached gigs | ✓ | — |
| Build and publish gigs | Limited | ✓ |
| CRM and leads pipeline | Limited | ✓ |
| Billing and subscription | — | ✓ |
| AI file ingestion (CheckAI) | — | ✓ |
| Import data | — | ✓ |

## Sign-in methods

The app supports the same sign-in methods as the web app:

- **Email + password** (iOS and Android)
- **Google** (iOS and Android)
- **Apple Sign In** (iOS only — not available on Android)

If you belong to multiple organizations, you pick which one to open after signing in and can switch later from the **You** tab.

---

## Push notifications and offline access

**Push notifications** put time-sensitive events on your lock screen — a new invitation, a crew response, an availability check — so you never miss something urgent.

**Offline support** keeps you working when venue Wi-Fi or cell reception is unreliable. The app caches recently viewed gigs and setlists so you can still read them when signal drops between sound check and downbeat.
