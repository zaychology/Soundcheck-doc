Most music and information commands work as soon as Soundcheck joins. Settings need a member with the right Discord permission.

| Feature | Who can change it | What Soundcheck needs |
| --- | --- | --- |
| Command and module controls, logs, levels settings | Manage Server | View and send messages in the target channel |
| Prefix, settings overview, reset, LEAKED.CX feeds | Administrator | Send messages in the feed channel |
| Song of the Day, bot profile customization | Administrator | Send messages and mention the role you pick |
| Level role rewards | Manage Server | Manage Roles, with its role above the reward roles |
| Emoji add, rename, delete | Manage Expressions | Manage Expressions |
| VoiceMaster setup | Manage Server | Manage Channels, Move Members, Manage Roles |
| Refresh snippets | Manage Messages | |

## The invite

The invite link asks only for what Soundcheck uses, not Administrator:

- **Messages:** View Channels, Send Messages, Send Messages in Threads, Read Message History, Embed Links, Attach Files, Add Reactions, Use External Emojis and Stickers, Use Slash Commands, Bypass Slowmode
- **Server tools:** Manage Channels, Move Members, Connect (VoiceMaster), Manage Roles (level rewards, VoiceMaster), Create and Manage Expressions (emoji commands), View Audit Log (event logs), Create Instant Invite

Keep these when you set up Soundcheck's role. Its role must sit above any role it gives out.

If a feature does nothing, check that both the member and Soundcheck can see the channel or role involved.
