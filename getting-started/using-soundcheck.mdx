## Run a command

Type `/` in any channel and pick a Soundcheck command, such as `/tracker unreleased`. Discord shows each command's options before you send it.

You can also mention the bot: `@Soundcheck tracker unreleased`. A few commands, such as `prefix` and `settings`, only work this way.

<Note>
Soundcheck can't read normal messages, so a custom prefix like `!tracker` is not available. Mention `@Soundcheck` instead.
</Note>

Run `/help` to browse categories, or `/help command:<name>` for one command.

## Pick an artist

Tracker, snippet and compilation commands take an optional artist or `tracker` option. Picking one each time is free.

To skip that step, a server manager can set a default with `/artist set`, and you can set your own with `/artist mine`. Both need [Premium](/administration/premium).

```text
/tracker unreleased tracker:Yeat title:talk
/snippets artist:Ken Carson
/tracker search title:sky
```

## Commands that need something from you

- `/identify` needs an audio file or a link to one.
- `/media spectrogram`, `/media tag` and `/media exiftool` need a file or a link.
- `/lastfm login` links your Last.fm account before `/lastfm now` and the chart commands can use it.
- `/download` needs a SoundCloud, TikTok, X or Pillowcase link.
