---
title: "Premium"
description: "Purchase, redeem, and check Soundcheck Premium."
---

Use `/premium buy` to begin a Premium purchase flow, `/premium status` to inspect the current server’s entitlement, and `/premium redeem` to apply a redemption code.

Premium applies to the server selected by the command flow. Make sure you run the command in the server you intend to upgrade.

<Note>
Premium administration commands such as assignment, removal, key checks, and diagnostics are restricted to bot operators and are not part of the public documentation.
</Note>

For billing questions, see the [refund policy](/legal/refunds).
