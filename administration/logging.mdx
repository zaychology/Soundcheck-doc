---
title: "Logging"
description: "Post server events to channels you choose."
---

Soundcheck can post server events, such as deleted messages, role changes and channel changes, to a channel you pick. Logging needs Manage Server.

| Command | What it does |
| --- | --- |
| `/log add <channel> <event>` | Post an event type to a channel |
| `/log remove <channel>` | Stop posting to a channel, or only one event with `event` |
| `/log status` | Show where each event goes |
| `/log ignore` | Stop logging a member or channel |
| `/log ignore list` | Show what's ignored |
| `/log ignore remove` | Start logging it again |

Soundcheck must be able to see and send messages in the log channel.

<Note>
Discord hasn't given Soundcheck access to message text or the member list, so message logs can't show what a message said, and join and leave events aren't logged.
</Note>
