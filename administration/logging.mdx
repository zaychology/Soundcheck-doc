---
title: "Logging"
description: "Send moderation and server event logs to dedicated Discord channels."
---

Soundcheck can post log events to a channel you choose. Configure a log with `/log add <event> <channel>` and remove it with `/log remove`.

## Management commands

| Command | Purpose |
| --- | --- |
| `/log status` | Show configured log destinations |
| `/log ignore` | Configure ignored targets for a log event |
| `/log ignore list` | List current ignored targets |
| `/log ignore remove` | Remove an ignored target |
| `/log bot add` | Configure bot-event logging |
| `/log bot remove` | Remove bot-event logging |
| `/log bot status` | Inspect bot-event logging |

Give Soundcheck access to the destination channel. If event logs do not appear, verify the bot can view and send messages there and has the permissions required for the event type.
