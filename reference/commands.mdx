Soundcheck has 187 commands and subcommands. Use them as slash commands, or by mentioning `@Soundcheck` (for example `@Soundcheck tracker search`). In Discord, `/help command:<name>` shows any command's options. The [website](https://soundcheckbot.xyz/commands) has the same list with search.

**Premium** commands need [Premium](/administration/premium). **Server only** commands don't work in DMs.
