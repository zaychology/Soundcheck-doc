title: "Command reference"

---

This reference lists public command families. Use `/help` in Discord for the live command schema and options, since inputs can change with Discord command registration.

## Artist and tracker

`/artist`, `/era`, `/surface`, `/trackerhub`, `/tracker`, `/trackerbeta`, `/snippets`, `/refreshsnippets`, and `/compilation` cover artist selection, custom eras, discovery, tracker search, snippets, and compilations. Artist-specific groups are documented in [supported artists](/reference/supported-artists).

## Media and music

`/spotify`, `/soundcloud`, `/youtube`, `/tiktok`, `/x`, `/exiftool`, `/tag`, `/spectrogram`, `/cover`, `/runtime`, `/identify`, and `/download` handle supported links and music files. `/genius` includes `artist`, `album`, `credits`, `related`, and `stats` lookups.

## Last.fm

`/lastfm now`, `login`, `logout`, `topartists`, `toptracks`, `topalbums`, `recent`, `whois`, `count`, and `color`; `/nowplaying` is a shortcut.

## VoiceMaster and levels

`/voicemaster` provides temporary-channel setup, configuration, defaults, and member controls. `/levels` provides XP, leaderboard, reward-role, ignore-list, and administration controls. See their dedicated guides for details.

## Server administration

`/cmd`, `/module`, `/bypass`, `/prefix`, `/welcome`, `/goodbye`, `/autorole`, `/log`, `/songoftheday`, `/customize`, `/settings`, and `/resetsettings` manage server behavior.

## Information and community

`/botinfo`, `/serverinfo`, `/userinfo`, `/channelinfo`, `/roleinfo`, `/membercount`, `/guildicon`, `/guildbanner`, `/splash`, `/avatar`, `/banner`, `/serveravatar`, `/serverbanner`, `/uptime`, `/ping`, `/emoji`, `/quickpoll`, `/afk`, `/embed`, `/topcommands`, `/weather`, and `/help` are available alongside the fun command set.

<Tip>
For prefix commands, replace `/` with your server prefix. A command may have aliases; Discord’s slash-command picker will display the canonical name.
</Tip>
