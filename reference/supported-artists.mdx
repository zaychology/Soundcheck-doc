Soundcheck offers curated tracker commands for the following artists:

| Artist command | Artist |
| --- | --- |
| `/yeat` | Yeat |
| `/playboicarti` | Playboi Carti |
| `/ye` | Ye (Kanye West) |
| `/travisscott` | Travis Scott |
| `/kendricklamar` | Kendrick Lamar |
| `/drake` | Drake |
| `/future` | Future |
| `/liluzivert` | Lil Uzi Vert |
| `/kencarson` | Ken Carson |
| `/destroylonely` | Destroy Lonely |
| `/dontoliver` | Don Toliver |
| `/osamason` | OsamaSon |
| `/summrs` | Summrs |
| `/rihanna` | Rihanna |
| `/joji` | Joji |
| `/pierrebourne` | Pi'erre Bourne |
| `/lanceyfoux` | Lancey Foux |
| `/slayr` | Slayr |
| `/dax` | Dax |
| `/sheffg` | Sheff G |
| `/kash` | Kash |
| `/edwardskeletrix` | Edward Skeletrix |

Each artist can expose a different subset of `tracker`, `unreleased`, `released`, `tracklists`, `art`, `era`, `recent`, `random`, `snippets`, and related commands. Start by running the artist group with no subcommand or use `/help` to see its currently available options.
